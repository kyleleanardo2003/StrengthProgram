# StrongmanCast Project Structure

The project still uses the normal Maven/Spring Boot layout, but the Java package has been shortened so the folders are easier to browse.

## Main Files

- `pom.xml` - project dependencies and build settings
- `src/main/resources/application.properties` - app settings, database, organizer username/password
- `src/main/resources/application-prod.properties` - online hosting settings for Postgres
- `src/main/resources/templates/` - website pages
- `src/main/resources/static/app.css` - site styling
- `src/main/resources/base-model/wrath-2025-seed.tsv` - autofill seed data
- `Dockerfile` - container build used for online hosting
- `render.yaml` - Render blueprint for the web service and Postgres database

## Java Code

- `src/main/java/strongmancast/StrongmanCompetitionApplication.java` - app startup
- `src/main/java/strongmancast/controller/` - website routes and form actions
- `src/main/java/strongmancast/model/` - competition, athlete, event, and result data shapes
- `src/main/java/strongmancast/repository/` - database access
- `src/main/java/strongmancast/service/` - shared app logic
- `src/main/java/strongmancast/config/` - security/login configuration
## Generated Or Local Folders

- `target/` is generated by Maven when the app builds.
- `data/` stores the local H2 database.

Those folders can be recreated by the app, so they are ignored by `.gitignore`.
